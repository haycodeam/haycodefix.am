HTML

  • HTML-ը կայքի կառուցվածքն է (structure)
  • Օգտագործվում է տեքստ, նկարներ և կոճակներ ավելացնելու համար
  • Հիմնական և առաջին քայլն է վեբ ծրագրավորման մեջ
  • Աշխատում է բոլոր բրաուզերներում

CSS

  • CSS-ը պատասխանատու է կայքի դիզայնի համար
  • Կառավարում է գույները, տառատեսակները և դասավորությունը
  • Ստեղծում է գեղեցիկ և ժամանակակից տեսք
  • Թույլ է տալիս կայքը դարձնել ադապտիվ (responsive)

Java Script

  • JavaScript-ը կայքին տալիս է ինտերակտիվություն
  • Օգտագործվում է կոճակների, ֆորմաների և իրադարձությունների համար
  • Թույլ է տալիս ստեղծել դինամիկ և «կենդանի» կայքեր
  • Կարելի է օգտագործել թե՛ frontend, թե՛ backend ծրագրավորման մեջ

React JS

  • React-ը գրադարան է՝ ինտերֆեյսներ ստեղծելու համար
  • Օգտագործում է component-ների կառուցվածք
  • Թույլ է տալիս արագ և արդյունավետ ստեղծել կայքեր
  • Օգտագործվում է իրական նախագծերում և IT ընկերություններում

Node JS

  • Node.js-ը թույլ է տալիս JavaScript-ը օգտագործել server-ի վրա
  • Օգտագործվում է backend ծրագրավորման համար
  • Արագ և արդյունավետ է մեծ նախագծերի համար
  • asdasd

Python

  • Python-ը պարզ և հեշտ ծրագրավորման լեզու է
  • Օգտագործվում է վեբ, AI, տվյալների վերլուծության մեջ
  • Ունի պարզ և ընթեռնելի սինտաքս
  • Լայն կիրառվում է սկսնակների և մասնագետների կողմից

PHP

  • PHP-ը server-side ծրագրավորման լեզու է
  • Օգտագործվում է վեբ կայքերի backend-ի համար
  • Հեշտ է ինտեգրել տվյալների բազաների հետ
  • Լայնորեն օգտագործվում է CMS-ներում (օր. WordPress)

C++

  • C++ ը հզոր ծրագրավորման լեզու է
  • Օգտագործվում է խաղերի, համակարգերի և բարձր արդյունավետ ծրագրերի համար
  • Թույլ է տալիս աշխատել hardware-ի մոտ մակարդակով
  • Շատ արագ և արդյունավետ լեզու է

C#

  • C#-ը Microsoft-ի կողմից ստեղծված ծրագրավորման լեզու է
  • Օգտագործվում է վեբ, desktop և խաղերի (Unity) համար
  • Ունի պարզ և հզոր կառուցվածք
  • Լայն կիրառվում է .NET framework-ում
